SCHRITT 1

WEN PRÜFEN WIR?

Wichtig

Nur kurze, natürliche Läufe auf gerader, ebener Strecke. Bitte abbrechen, wenn dein Hund unwohl wirkt oder nicht ruhig laufen möchte.

EMPFOHLEN FÜR DIE BETA

HARNELYZER BASE SOLO

Für den Start genügt ein Smartphone mit Halter oder Stativ, eine ruhige Strecke und drei klar markierte Positionen.

  • Position A: Seite · 90 Grad
  • Position B: Vorne schräg · 45 Grad
  • Position C: Hinten schräg · 135 Grad
  • Gleiche Strecke, gleicher Untergrund, kurze Läufe
